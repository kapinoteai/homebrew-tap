# homebrew-tap

The Homebrew tap for [Kapinote](https://kapinote.com/).

```bash
brew install --cask kapinoteai/tap/kapinote
```

## Notes

`Casks/kapinote.rb` is generated by Kapinote's release script and published to
this tap and to `guangzhengli/tap` at the same time. Kapinote shipped from that
tap for its first 34 releases and a cask cannot redirect, so the older one is
kept alive for the people already installed from it. Do not edit the cask by
hand in either place.

Downloads are served from `https://dl.kapinote.com` (Cloudflare R2). Every
version is an immutable object under `/v<version>/`, which is what lets the cask
pin a `sha256`.

The app also updates itself through Tauri's updater, so the cask declares
`auto_updates true` and `brew upgrade` leaves it alone unless you pass
`--greedy`.
